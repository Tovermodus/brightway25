Note from the brightway25 code map: this page is generated straight from bw2calc's installed docstrings, so a few things worth knowing aren't stated here. use_distributions=True makes an LCA object itself an iterator — call next(lca) repeatedly to resample every uncertain matrix entry and get a new lca.score each time (Monte Carlo); use_arrays=True is the sibling flag for scenario/array-based iteration via the same mechanism. See the Monte Carlo uncertainty tutorial for a full worked example, and the bw2calc module map for how this fits into the rest of the calculation stack.
