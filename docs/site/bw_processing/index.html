bw_processing

The on-disk "datapackage" format Brightway uses to store technosphere, biosphere, and characterization matrix data — structured numpy (or Parquet) arrays plus JSON metadata, written by bw2data and read by bw2calc/matrix_utils to build live scipy matrices.

Main classes & entry points

Datapackage

datapackage.py — the concrete read/write datapackage. add_persistent_vector, add_persistent_array, add_entries, add_csv_metadata, add_json_metadata, get_resource, filter_by_attribute.

create_datapackage()

datapackage.py — build a new, empty Datapackage (in-memory DictFS by default, or a given fsspec filesystem).

load_datapackage()

datapackage.py — read an existing datapackage from a filesystem, with optional mmap_mode / proxy=True lazy loading.

MatrixEntry / ArrayEntry

matrix_entry.py — dataclasses describing one matrix cell (or a whole scenario-array group): row, col, amount, flip, uncertainty params, rescale, reference.

create_datapackage_from_entries()

matrix_entry.py — recommended high-level constructor: {MatrixName: [MatrixEntry, ...]} → Datapackage, no raw numpy needed.

MatrixName

matrix_entry.py — str Enum of standard matrix names: technosphere, biosphere, characterization.

Typical usage

from bw_processing import (
    create_datapackage_from_entries,
    load_datapackage,
)
from bw_processing.matrix_entry import MatrixEntry, MatrixName

# Build a datapackage from plain Python objects
dp = create_datapackage_from_entries(
    {
        MatrixName.technosphere: [
            MatrixEntry(row=0, col=0, amount=1.0),           # production
            MatrixEntry(row=1, col=0, amount=2.5, flip=True),  # input, consumed
        ],
        MatrixName.biosphere: [
            MatrixEntry(row=10, col=0, amount=0.3),
        ],
    },
    name="my-first-datapackage",
)

# Persist it to disk
from bw_processing import generic_directory_filesystem
dp.fs = generic_directory_filesystem(dirpath="./my-datapackage")
dp.finalize_serialization()

# ...later, read it back (e.g. the way bw2calc/matrix_utils do)
dp2 = load_datapackage(generic_directory_filesystem(dirpath="./my-datapackage"))
data_array, indices_array, flip_array = dp2.get_resource("my-first-datapackage-data.data")

Where to look

What does a datapackage actually contain on disk?

constants.py for the fixed dtypes (INDICES_DTYPE, UNCERTAINTY_DTYPE), and Datapackage.add_persistent_vector / add_persistent_array in datapackage.py for how each resource group (indices, data, distributions, flip, rescale, reference) becomes its own .npy/.parquet file plus an entry in the JSON metadata resource list.

How is uncertainty encoded?

UNCERTAINTY_DTYPE in constants.py (fields uncertainty_type, loc, scale, shape, minimum, maximum, negative). The integer uncertainty_type codes are defined by stats_arrays (0/1 = no uncertainty, 2 = lognormal, 3 = normal, etc). See the MatrixEntry docstring in matrix_entry.py.

What's the easiest way to build a datapackage without raw numpy?

matrix_entry.create_datapackage_from_entries() with a {MatrixName: [MatrixEntry(...), ...]} dict. Internally it calls Datapackage.add_entries → add_persistent_vector_from_iterator → utils.resolve_dict_iterator in datapackage.py / utils.py.

How do I read a datapackage back and get a resource's array?

datapackage.load_datapackage() (pass an fsspec filesystem, e.g. from io_helpers.generic_directory_filesystem / generic_zipfile_filesystem; use mmap_mode or proxy=True for lazy loading of large arrays), then Datapackage.get_resource(name_or_index) in datapackage.py.

How do flip / rescale / reference exchanges work?

Per-entry fields on MatrixEntry/ArrayEntry in matrix_entry.py. When set, they're written as separate resources (kind="flip"/"rescale"/"reference") alongside the main data/indices arrays inside Datapackage.add_persistent_vector / add_persistent_array in datapackage.py.

How are several datapackages combined, or indices renumbered?

merging.merge_datapackages_with_mask() to combine packages with a per-package boolean row mask, and indexing.reindex() / indexing.reset_index() to remap row/col index values in place.
Related modules:
bw2data — writes datapackages via DataStore.process(); the main producer of this format.
bw2calc — reads datapackages (via matrix_utils) to build and solve LCA matrices.
matrix_utils — consumes datapackage resource groups directly to assemble scipy sparse matrices.
stats_arrays — defines the uncertainty distribution type codes stored in UNCERTAINTY_DTYPE.
