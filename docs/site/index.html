Brightway 2.5 — code map

This repository (brightway25) is only a meta-package that pins the Brightway 2.5 dependency stack — see pyproject.toml. The real code for every package below lives on PyPI / GitHub and is installed locally into .venv/lib/python3.11/site-packages/ via pip install -e ".[dev]". These pages map that installed source so you can navigate it without relying on (often stale) upstream docs.

Recreate the source locally with: 
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
then open docs/site/index.html in a browser (no server needed — plain file:// links).

Architecture — how the pieces fit together

stats_arrays   bw2parameters            (leaf utility libs: uncertainty, formulas)
        \           /
     bw_processing ── matrix_utils ── bw_graph_tools
              \            |              /
               \           |             /
                bw2data (projects, activities, exchanges)
                     |
              multifunctional (allocation, sits on top of bw2data)
                     |
                  bw2calc (LCA solving; matrices via matrix_utils)
                     |
                  bw2analyzer (post-processing of bw2calc results)

Core data model
bw2data

Projects, SQLite-backed activities/exchanges, methods, metadata — the central data store everything else reads/writes.

Processed data & matrices
bw_processing

On-disk "datapackage" format for matrix-ready arrays.

matrix_utils

Builds bw_processing datapackages into live scipy sparse matrices.

bw_graph_tools

Graph traversal of the technosphere / supply-chain graphs.

Calculation & analysis
bw2calc

LCA calculation engine: builds & solves the matrices.

bw2analyzer

Post-calculation analysis: contribution, comparisons, graphs.

multifunctional

Allocation of multi-output ("multifunctional") processes.

Parameters & uncertainty
bw2parameters

Formula/parameter interpreter for parameterized exchanges.

stats_arrays

Uncertainty distributions + Monte Carlo RNG.

Import / export & interop
bw2io

Import/export: ecoinvent, SimaPro, ecospold, Excel, exiobase, etc.

bw_simapro_csv

Low-level SimaPro CSV parser used by bw2io.

ecoinvent_interface

Authenticated client for downloading ecoinvent releases.

bw_migrations

Curated data migrations (e.g. exiobase↔ecoinvent) used during import.

randonneur

Generic "migrate/patch a dataset" engine.

randonneur_data

Registry of pre-built randonneur migration datasets.

mrio_common_metadata

Shared metadata helpers for MRIO (exiobase-style) datapackages.
