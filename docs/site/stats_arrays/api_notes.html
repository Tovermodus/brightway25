Note from the brightway25 code map: this page is generated straight from stats_arrays's installed docstrings, so a few things worth knowing aren't stated here. The integer uncertainty_type codes are verified from the installed uncertainty_types.py UncertaintyType(IntEnum): normal == 3, lognormal == 2 (also each distribution class's own id attribute, e.g. NormalUncertainty.id == 3). For lognormal, loc is the underlying normal's mean in log-space (mu, i.e. log(median)) rather than the median itself — confirmed from distributions/lognormal.py random_variables(), which samples numpy.random.lognormal(loc, scale) directly. See the Monte Carlo uncertainty tutorial for a full worked example built on these codes, and the stats_arrays module map for how this fits into the rest of the uncertainty/sampling stack.
