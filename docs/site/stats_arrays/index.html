stats_arrays

Uncertainty distribution definitions and Monte Carlo random number generation, shared across the Brightway stack for representing and sampling parameter/exchange uncertainty (means, standard deviations, bounds, distribution shape).

Numeric type codes and UncertaintyBase

Every distribution class carries a class attribute id — a small integer < 256 — that identifies it, plus a description string. UncertaintyType (uncertainty_types.py) is an IntEnum giving names to the same integers (UncertaintyType.normal == 3 == NormalUncertainty.id), and uncertainty_choices (uncertainty_choices.py) is a registry that looks a distribution class up by that integer: uncertainty_choices[UncertaintyType.normal] is NormalUncertainty.

Parameters for one or more distributions are stored in a "params array" — a numpy structured array with fields loc, scale, shape, minimum, maximum, negative, and (usually) uncertainty_type (see utils.py's BASE_DTYPE_FIELDS). This exact field layout — same names, same order — is mirrored by bw_processing.constants.UNCERTAINTY_DTYPE (which uses float32 instead of float64), so an uncertainty resource read out of a datapackage can be handed straight to stats_arrays' RNG classes without conversion.

Typical usage

from stats_arrays import (
    UncertaintyBase,
    TriangularUncertainty,
    MCRandomNumberGenerator,
    RandomNumberGenerator,
)

# Single distribution type: build a params array and sample directly
params = TriangularUncertainty.from_dicts(
    {"loc": 5, "minimum": 3, "maximum": 10},
    {"loc": 1, "minimum": 0.7, "maximum": 4.4},
)
rng = RandomNumberGenerator(TriangularUncertainty, params, seed=42)
samples = rng.generate_random_numbers()  # one row of samples per params row

# Mixed distribution types in a single array, keyed by uncertainty_type id
params = UncertaintyBase.from_dicts(
    {"loc": 5, "minimum": 3, "maximum": 10, "uncertainty_type": 5},  # triangular
    {"loc": 1, "scale": 0.7, "uncertainty_type": 3},                 # normal
)
mcrng = MCRandomNumberGenerator(params, seed=42)
next(mcrng)   # one Monte Carlo draw per row, dispatched to the right distribution

Where to look

How do I know which integer code means which distribution?

uncertainty_types.py — UncertaintyType(IntEnum), e.g. normal = 3, lognormal = 2, triangular = 5, beta_pert = 13. Each distribution class's id attribute equals the same integer, and uncertainty_choices[id] (uncertainty_choices.py) resolves an integer to its class.

What's the shape/dtype of a "params array"?

utils.py — BASE_DTYPE_FIELDS / BASE_DTYPE define the numpy structured dtype (loc, scale, shape, minimum, maximum, negative, plus uncertainty_type when include_type=True). construct_params_array() builds an empty one; UncertaintyBase.from_tuples() / UncertaintyBase.from_dicts() (distributions/base.py) build one from plain Python data.

How do I sample from an array containing several different distribution types?

random.py's MCRandomNumberGenerator sorts rows by uncertainty_type, groups them via get_positions(), calls each distribution's bounded_random_variables()/random_variables() per group, then restores the original row order. Use plain RandomNumberGenerator instead when every row is the same distribution type.

How do I add a new distribution?

Add a distributions/<name>.py module with a class subclassing UncertaintyBase (or BoundedUncertaintyBase for a [minimum, maximum] bounded distribution) in distributions/base.py. Set a unique id (< 256) and a description, then register the class in the DISTRIBUTIONS tuple in uncertainty_choices.py so it is picked up by uncertainty_choices and MCRandomNumberGenerator.

What exceptions can this package raise, and when?

errors.py — e.g. InvalidParamsError (bad params array on construction), ImproperBoundsError / UnreasonableBoundsError (bad or too-narrow min/max), MaximumIterationsError (couldn't sample within bounds in maximum_iterations tries), UnknownUncertaintyType (id not registered in uncertainty_choices), MultipleRowParamsArrayError (a function needing a single-row params array got several — see the one_row_params_array decorator in utils.py).

How do PDF/CDF/percentile calculations work?

distributions/base.py's UncertaintyBase.pdf(), .cdf(), .ppf(), .statistics() are classmethods every concrete distribution implements/overrides (built on SciPy); default_number_points_in_pdf (200) and standard_deviations_in_default_range (2.2) control default resolution/range.

Related modules:
bw_processing — stores exchange/parameter uncertainty using the same field layout in UNCERTAINTY_DTYPE (mirrors stats_arrays' params array dtype).
bw2calc — its Monte Carlo LCA classes sample from datapackage uncertainty data using stats_arrays' RNG classes.
bw2data — writes exchange/parameter uncertainty (uncertainty type + params) that ends up in this format.
bw2parameters — parameterized exchanges that also carry uncertainty distributions defined here.
