LCA Software Course

Seven step-by-step tutorials that take someone new to Brightway from an empty project to running real LCA workflows — inventory building, calculation, importing data, contribution analysis, uncertainty, allocation, and parameterization. Each is a slower-paced walkthrough than the Examples page: numbered steps, an explanation of what each API call actually does (grounded in the installed source, not memory or upstream docs), and a full runnable script at the end.

Every tutorial's code was actually executed against the installed source (.venv/lib/python3.11/site-packages/) to produce the output shown on that page — see each tutorial's own verification note. This course doesn't replace formal LCA theory (ISO 14040/14044 goal & scope, LCIA methods, interpretation) — it's the "how do I actually do this in the software" half. Pair it with any general LCA methodology course.

Suggested pacing

Modules 1-2 assume nothing beyond Python and the pip install -e ".[dev]" setup on the root page. Modules 3-4 assume 1-2. Modules 5-7 are independent of each other but each assumes 1-2 — take them in any order once you're comfortable with a basic inventory and LCA run.

Where this fits

This course teaches the software — the same distinction the Examples page and each module's reference page draw between "what is this API" and "how do the pieces get used together." It assumes you already know (or are separately learning) LCA methodology itself: goal & scope, the ISO 14040/14044 framework, impact assessment methods, and interpretation. For that half, see a general LCA methodology course; university courses that specifically teach the Brightway stack (rather than a different tool) include NTNU's "Advanced Programming for Environmental Systems Analyses with Brightway" and ILCA's Brightway 2.5 training.
